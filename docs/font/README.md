# خط ثمانية (Thmanyah)

هذه الملفات من عائلة **ثمانية** المستخدمة في صفحة `docs/index.html`:

- `thmanyah-sans-*.woff2` و`thmanyah-sans-*.ttf` — للنصوص والواجهة (الـWOFF2 هو المستخدم في الصفحة، والـTTF محفوظ كمصدر/احتياط).
- `thmanyah-serif-display-*.woff2` — للعناوين والبطاقات.

المصدر: حزمة الويب المجتمعية
<https://github.com/EngDawood/thmanyah-font-web>
والخط من تصميم وملكية **ثمانية**:
<https://font.thmanyah.com>

> راجع ترخيص الخط قبل إعادة التوزيع. الاستخدام هنا شخصي/تعريفي داخل المشروع.
